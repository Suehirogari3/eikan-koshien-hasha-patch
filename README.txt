「栄冠は君に 甲子園の覇者」 練習試合バグ修正パッチ
=====================================================

■ 対象ソフト
  SLPS-25053 「栄冠は君に 甲子園の覇者」(ARTDINK, Ver.1.02)
  CRC: 77E8D14C

  ※重要: このCRC(77E8D14C)は、ゲームのディスクイメージ自体の
    中身から計算される値であり、使用しているパソコンやPCSX2の
    設定によって変わるものではありません。同じゲームソフト・
    同じバージョンのディスクイメージであれば、どなたの環境でも
    必ず同じCRCになります。したがって、
      ・ファイル名(77E8D14C の部分)は変更しないでください
      ・削除する必要もありません
    そのままのファイル名で配置していただければ、PCSX2が自動的に
    対象のゲームを認識して適用します。ファイル名を変更すると、
    逆にPCSX2がこのパッチを認識できなくなり、一切適用されなく
    なりますのでご注意ください。

    もし手元のディスクイメージのバージョンやリージョンが異なる
    場合は、PCSX2のログ(またはGame Properties画面)に表示される
    CRCが 77E8D14C と一致するかどうかで判断できます。一致しない
    場合はPCSX2側がこのファイルを単純に無視するだけなので、
    誤動作の心配はありません。

■ 修正内容(計3件)
  1. 練習試合の対戦相手が池田高校に固定される問題
     予定表配列(全66件)が満杯になったとき、新しい練習試合の
     書き込みを諦めてしまい、結果として無関係な過去のデータ
     (池田高校)が「今日の試合」として表示され続けていた問題を
     修正。配列が満杯でも、再利用可能なスロット(スロット0)へ
     書き込みが行われるようにした。

  2. 練習試合を組んでいないのに、無関係な相手校との練習試合が
     突然発生する問題(通称: 幽霊試合)
     その日に該当する練習試合が予定表配列内に見つからない場合、
     本来は「今日は何もない」とすべきところを、無関係なスロット0
     の中身を誤って「今日の試合」として表示してしまっていた問題を
     修正。検索に失敗した場合は、ゲーム内に既存する「出場可能な
     選手が9人未満のため試合を中止する」処理へ安全に迂回させる
     ことで対応した。

  3. 年間目標の達成判定が誤り、目標が「飛び級」して表示される問題
     (v1.1で追加)
     今日の日付・勝敗条件に一致する目標階層をキューから検索する
     処理は、一致したエントリのインデックスを正しく求めていた
     にもかかわらず、そのインデックスを使ったアドレス計算の結果
     (mult命令の乗算結果)をmflo命令で受け取る処理が欠落しており、
     計算結果が破棄されていた。そのため実際にどのエントリが一致
     したかに関わらず、常にキュー内の固定された2番目のスロットの
     データが「達成した目標」として採用されてしまっていた。シーズン
     中に複数の目標階層が積み重なると、本来とは無関係な(たいてい
     後方の、より難しい)目標の達成メッセージが表示され、あたかも
     目標が一気に「飛び級」したかのように見える不具合の原因だった。
     修正では、ループ内で既に正しく該当エントリを指していたポインタ
     (レジスタs1)をそのまま使うようにし、無駄になっていた乗算結果
     への依存を無くした。

  いずれも新規コードの追加は行わず、既存の命令を並べ替える(または
  1命令だけ置き換える)最小限の修正です。

■ 導入方法(2種類のファイルがあります。どちらか一方だけを使ってください)

  【方法A: Patches形式(推奨・常時自動適用)】
  ファイル: SLPS-25053_77E8D14C.pnach
  1. PCSX2の設定画面(Interface もしくは Folders)で「Patches」
     フォルダの場所を確認してください(通常は
     Documents\PCSX2\patches\)。
  2. このファイルを、そのフォルダにコピーしてください。
  3. PCSX2の設定で EnablePatches が有効になっていることを確認
     してください(デフォルトで有効です)。
  4. ゲームを起動(またはリセット)すると自動的に適用されます。
     個別にON/OFFする操作は不要です。

  【方法B: Cheats形式(Game PropertiesのCheatsタブで個別ON/OFF)】
  ファイル: SLPS-25053_77E8D14C_Cheats形式.pnach
  1. PCSX2の設定画面(Interface もしくは Folders)で「Cheats」
     フォルダの場所を確認してください(環境によって異なりますが、
     多くの場合 resources フォルダ以下です)。
  2. このファイルを、そのフォルダにコピーしてください。
  3. PCSX2でゲームを右クリック→「Properties」→「Cheats」タブを
     開き、以下の3つのチェックボックスをONにしてください。
       ・練習試合の対戦相手が池田高校に固定されるバグの修正
       ・組んでいない相手校との練習試合(幽霊試合)が発生するバグの修正
       ・年間目標の達成判定バグ(目標の飛び級)の修正
     ※チェックを入れないと適用されません。ゲームを起動し直す
       (またはリセットする)と反映されます。

  普段チートツールを使い慣れていない方には方法Aを推奨します。
  他のチートと合わせて個別に管理したい場合は方法Bをご利用ください。

■ 検証状況
  ・問題1(池田高校固定)は実機で完全に再現しなくなったことを
    複数回確認済み。
  ・問題2(幽霊試合)は、パッチ適用後に約2年分のプレイで再発
    しないことを確認済み(発生頻度がもともと低い問題のため、
    完全な保証ではありません)。
  ・パッチ適用後も、日付の進行、通常の練習試合の発生、年間目標
    達成時の練習機材贈呈イベントに異常がないことを確認済み。
  ・この2つの修正は、練習試合の相手校の学校ID・都道府県には
    一切依存しないロジック(配列のインデックス管理と日付検索のみ)
    を対象としているため、特定の都道府県の学校でのみ発生する
    可能性は低いと考えられます。
  ・問題3(目標の飛び級、v1.1で追加)は、静的解析(逆コンパイル・
    生のMIPS命令列の確認)によって原因を特定し、書き換え後の命令の
    意味・パッチバイトの適用結果はいずれも検証済みです。ただし、
    この不具合自体が発生条件を狙って再現しづらい性質のため、修正
    パッチを当てた状態での実際のプレイによる再発テストはまだ行って
    いません。動作報告をいただけると助かります。
