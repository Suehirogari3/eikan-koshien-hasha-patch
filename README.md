# 栄冠は君に 甲子園の覇者 - 練習試合バグ修正パッチ

対象ソフト: **SLPS-25053 「栄冠は君に 甲子園の覇者」**(ARTDINK, Ver.1.02) / CRC: `77E8D14C`

PCSX2で本作をプレイする際に発生する、練習試合まわりの2つの不具合と、年間目標の達成判定に関する1つの不具合、計3件を修正するパッチです。

> **CRCについて**: `77E8D14C` はディスクイメージの中身から計算される値で、パソコンやユーザー環境には依存しません。同じゲーム・同じバージョンであれば誰の環境でも同じ値になるため、ファイル名はそのままで問題なく使用できます。

## ダウンロード

[Releases](../../releases) から `配布用パッチ.zip` をダウンロードしてください。

## 修正内容

### 1. 練習試合の対戦相手が池田高校に固定される問題
予定表配列(全66件)が満杯になったとき、新しい練習試合の書き込みを諦めてしまい、結果として無関係な過去のデータ(池田高校)が「今日の試合」として表示され続けていた問題を修正。配列が満杯でも、再利用可能なスロットへ書き込みが行われるようにした。

### 2. 練習試合を組んでいないのに、無関係な相手校との練習試合が発生する問題(通称: 幽霊試合)
その日に該当する練習試合が予定表配列内に見つからない場合、本来は「今日は何もない」とすべきところを、無関係なスロットの中身を誤って「今日の試合」として表示してしまっていた問題を修正。検索に失敗した場合は、ゲーム内に既存する「出場可能な選手が9人未満のため試合を中止する」処理へ安全に迂回させることで対応。

### 3. 年間目標の達成判定が誤り、目標が「飛び級」して表示される問題(v1.1で追加)
今日の日付・勝敗条件に一致する目標階層をキューから検索する処理は、一致したエントリのインデックスを正しく求めていたにもかかわらず、そのインデックスを使ったアドレス計算の結果(`mult`命令の乗算結果)を`mflo`命令で受け取る処理が欠落しており、計算結果が破棄されていた。そのため実際にどのエントリが一致したかに関わらず、常にキュー内の固定された2番目のスロットのデータが「達成した目標」として採用されてしまっていた。シーズン中に複数の目標階層が積み重なると、本来とは無関係な(たいてい後方の、より難しい)目標の達成メッセージが表示され、あたかも目標が一気に「飛び級」したかのように見える不具合の原因だった。修正では、ループ内で既に正しく該当エントリを指していたポインタ(レジスタ`s1`)をそのまま使うようにし、無駄になっていた乗算結果への依存を無くした。

いずれも新規コードの追加は行わず、既存の命令を並べ替える(または1命令だけ置き換える)最小限の修正です。

## 導入方法

ZIP内に2種類のファイルがあります。**どちらか一方だけ**を使ってください。

### 方法A: Patches形式(推奨・常時自動適用)
ファイル: `SLPS-25053_77E8D14C.pnach`

1. PCSX2の設定(Interface / Folders)で「Patches」フォルダの場所を確認(通常は `Documents\PCSX2\patches\`)
2. このファイルをそのフォルダにコピー
3. `EnablePatches` が有効になっていることを確認(デフォルトで有効)
4. ゲームを起動(またはリセット)すると自動的に適用されます。ON/OFF操作は不要です

### 方法B: Cheats形式(Game PropertiesのCheatsタブで個別ON/OFF)
ファイル: `SLPS-25053_77E8D14C_Cheats形式.pnach`

1. PCSX2の設定(Interface / Folders)で「Cheats」フォルダの場所を確認(多くの場合 `resources` フォルダ以下)
2. このファイルをそのフォルダにコピー
3. ゲームを右クリック→「Properties」→「Cheats」タブで、以下3つのチェックボックスをON
   - 練習試合の対戦相手が池田高校に固定されるバグの修正
   - 組んでいない相手校との練習試合(幽霊試合)が発生するバグの修正
   - 年間目標の達成判定バグ(目標の飛び級)の修正
4. ゲームを起動し直すと反映されます

普段チートツールを使い慣れていない方には方法Aを推奨します。

## 検証状況

- 問題1(池田高校固定)は実機で完全に再現しなくなったことを複数回確認済み
- 問題2(幽霊試合)は、パッチ適用後に約2年分のプレイで再発しないことを確認済み(発生頻度がもともと低い問題のため、完全な保証ではありません)
- パッチ適用後も、日付の進行、通常の練習試合の発生、年間目標達成時の練習機材贈呈イベントに異常がないことを確認済み
- この2つの修正は、練習試合の相手校の学校ID・都道府県には一切依存しないロジック(配列のインデックス管理と日付検索のみ)を対象としているため、特定の都道府県の学校でのみ発生する可能性は低いと考えられます
- 問題3(目標の飛び級、v1.1で追加)は、静的解析(逆コンパイル・生のMIPS命令列の確認)によって原因を特定し、書き換え後の命令の意味・パッチバイトの適用結果はいずれも検証済みです。ただし、この不具合自体が発生条件を狙って再現しづらい性質のため、**修正パッチを当てた状態での実際のプレイによる再発テストはまだ行っていません**。動作報告をいただけると助かります
