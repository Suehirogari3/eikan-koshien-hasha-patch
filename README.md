# 栄冠は君に 甲子園の覇者 - 不具合修正パッチ

対象ソフト: **SLPS-25053 「栄冠は君に 甲子園の覇者」**(ARTDINK, Ver.1.02) / CRC: `77E8D14C`

PCSX2で本作をプレイする際に発生する不具合を修正するパッチ集です。**v1.2** で「年間目標が実際の戦績と乖離する」問題への修正(アプローチ2a+2b)と、OB機材贈呈イベントの修正を追加しました。

> **CRCについて**: `77E8D14C` はディスクイメージの中身から計算される値で、パソコンやユーザー環境には依存しません。同じゲーム・同じバージョンであれば誰の環境でも同じ値になるため、ファイル名はそのままで問題なく使用できます。

## ダウンロード

このリポジトリ直下の `配布用パッチ.zip` をダウンロードしてください(PCSX2用の`.pnach`パッチ3種とこのREADMEが入っています)。

実機PS2/PS3用のIPSパッチ、実機チート機器用のRAWコードは、それぞれ [実機PS2・PS3用パッチ_使い方.md](実機PS2・PS3用パッチ_使い方.md) / [実機チート機器用パッチ_使い方.md](実機チート機器用パッチ_使い方.md) を参照してください。**アプローチ2bは空きメモリ常駐ルーチンのため、実機ISO用IPSには含められません(下記「実機での制限」参照)。**

過去のバージョン(v1.0/v1.1)が必要な場合は [Releases](../../releases) から個別に取得できます。

## 収録パッチと修正内容

配布ZIPには3つの`.pnach`ファイルが入っており、それぞれの中に複数のトグル可能な修正エントリがあります。PCSX2のGame Properties→「Patches」タブで、適用したいものだけを個別にON/OFFできます。

### `SLPS-25053_77E8D14C.pnach` — 基本の不具合修正(v1.1、3件)

**1. 練習試合の対戦相手が池田高校に固定される問題**
予定表配列(全66件)が満杯になったとき、新しい練習試合の書き込みを諦めてしまい、無関係な過去のデータ(池田高校)が「今日の試合」として表示され続けていた問題を修正。配列が満杯でも再利用可能なスロットへ書き込むように変更。

**2. 組んでいない相手校との練習試合が発生する問題(通称: 幽霊試合)**
その日に該当する練習試合が予定表配列内に見つからない場合、本来「今日は何もない」とすべきところを、無関係なスロットの中身を誤って表示していた問題を修正。検索失敗時は、既存の「出場可能選手が9人未満のため中止」処理へ安全に迂回。

**3. 年間目標の達成判定が誤り、目標が「飛び級」して表示される問題**
`mult`命令の乗算結果を`mflo`で受け取る処理が欠落し、常にキュー内2番目のスロットが「達成した目標」として採用されていた。複数の目標階層が積み重なると無関係な(たいてい後方の、より難しい)達成メッセージが出て、目標が一気に飛び級したように見える原因。ループ内で既に正しいエントリを指していたポインタ(`s1`)をそのまま使うよう修正。

### `SLPS-25053_77E8D14C_達成レベル修正.pnach` — 達成レベルの補正(v1.2、2エントリ / 2a・2bセット運用)

**4. 達成レベルが実戦績と乖離し、意味不明な年間目標が出る問題**

`team_base+0x109B`(内部の「達成レベル」)は本来チーム作成時とハード目標失敗時にしか更新されず、甲子園での勝ち上がりを反映しません。そのため「甲子園に一度も出ていないのに"夏の全国大会連覇"が次の目標に出る」といった状態が発生します。

- **アプローチ2a(甲子園出場パッチ)**: 夏の甲子園の組み合わせ抽選で自チームが実際に選出された瞬間をフックし、達成レベルが「甲子園出場」(5)未満なら5に引き上げます。
- **アプローチ2b(達成レベル←トーナメント表)**: シーズン終了時に内部のトーナメント表(Table A/B)から自チームの最高進出段階を読み直し、達成レベルを補正します。地方大会の深さ→段階1〜4、春夏の甲子園→段階5〜9。全年度の最高値を採用。達成レベルが10以上の壊れた値なら計算値で上書き、それ未満なら引き上げのみ(正当な戦績は下げません)。自チームIDは固定値ではなく実行時に読み取るので、既存校を引き継いだプレイでも正しく動作します。

> **この2つは必ずセットで有効化してください。** また、**この修正は年間目標の進行そのものを変えます**。バニラの目標挙動を保ちたい場合はこのファイルの2エントリをOFF(またはファイルを入れない)のままにしてください。基本の不具合修正(1〜3)とは独立しています。
>
> 現在のバージョンは**段階1〜9まで**を扱います。段階10〜19(夏の全国大会制覇・連覇…)の挙動は今後のパッチ課題です。

### `SLPS-25053_77E8D14C_OBギフト確実発生版.pnach` — OB機材贈呈の修正(v1.2、1エントリ)

**5. OB機材贈呈が目標達成年でも確率で発生しないことがある問題**
卒業式のOB機材贈呈は「年間目標を達成/超過(内部diff≥0)」かつ確率ロール成功のときに発生します。本パッチは達成年の確率ロールだけを外し、達成していれば(未入手アイテムが残る限り)必ず発生させます。**目標未達成の年は従来どおり発生しません。** アプローチ2b併用時は、この判定が実際の戦績と連動します。

## 導入方法(PCSX2)

1. PCSX2の設定(Interface / Folders)で「Patches」フォルダの場所を確認(通常は `Documents\PCSX2\patches\`)
2. ZIP内の`.pnach`ファイルを、使いたいものだけそのフォルダにコピー
   - 基本の不具合修正だけ欲しい → `SLPS-25053_77E8D14C.pnach` のみ
   - 達成レベルの補正も欲しい → `..._達成レベル修正.pnach` も追加
   - OB機材贈呈の確実化も欲しい → `..._OBギフト確実発生版.pnach` も追加
3. 設定で `EnablePatches` が有効になっていることを確認(デフォルトで有効)
4. ゲームを起動(または一度シャットダウンして再起動)すると、各ファイル内の修正エントリが「Patches」タブに一覧表示されます。**必要なものにチェックを入れてください**(基本の3件はチェック推奨、達成レベル修正の2件はセットで、OB機材贈呈は任意)

## 実機での制限(重要)

- **アプローチ2b は実機ISO用IPSに含められません。** 2bは書き換えたルーチンをゲーム未使用のメモリ領域(`0x01F00000`)に常駐させ毎フレーム再書き込みする方式で、ISOファイル内に対応する領域が存在しないためです。
- 実機向けには **アプローチ2a のみを IPS で** 提供します(`eikan_koshien_hasha_approach2a_precise.ips`)。2aだけでも「甲子園出場を全く反映しない」最悪ケースは緩和されますが、段階6〜9(甲子園でのベスト16〜制覇)の補正は行われません。
- **2a+2b の完全版を実機で使いたい場合**は、RAWコード形式(`eikan_koshien_hasha_approach2a_2b_combined_raw.txt`、約190行)を、その行数に対応できるチート機器/ホームブリューCheatDeviceで読み込んでください。詳細は [実機チート機器用パッチ_使い方.md](実機チート機器用パッチ_使い方.md)。

## 検証状況

- **問題1(池田高校固定)**: 実機で完全に再現しなくなったことを複数回確認済み
- **問題2(幽霊試合)**: パッチ適用後に約2年分のプレイで再発しないことを確認済み(もともと発生頻度が低いため完全な保証ではありません)
- **問題3(目標の飛び級)**: 静的解析で原因を特定し、書き換え後の命令の意味・パッチバイトの適用結果を検証済み。狙って再現しづらい不具合のため実プレイでの再発テストは限定的
- **問題4(達成レベル乖離、v1.2) / アプローチ2b**: セーブステート + PINEメモリ書き換えによる13ケースの注入テストで全パス。地方大会 段階1〜5 のラダーがギャップなく1段ずつ上がること、甲子園優勝→段階9、壊れた達成レベル(≥10)の再計算、シーズン終了ラチェットの目標更新条件、いずれも設計どおり動作。実プレイでも自然な1年分で目標が「地方大会緒戦突破」→「地方大会ベスト4以内」へ正しく更新され、表示も正常なことを確認。2b(2a+2b両方をロードした状態)で長期プレイ中のクラッシュや異常は今のところ確認されていません
- **問題4 / アプローチ2a**: 常駐先アドレス(`0x002271DC`、関数外の未使用パディング領域)は、Ghidraの参照DBではなく生バイトスキャンで「呼び出し・ジャンプ・データ参照が一切無い」ことを確認済み(過去に別の"空きに見えて実は生きていたコード"へ当ててクラッシュした反省から導入した検証手順)。書き換えロジック自体は7命令と単純で手検証済み。**ただし2aのトリガー(夏の甲子園抽選で自チームが選出される瞬間)が実際に発火する場面は、まだ実プレイで踏めていません**(テストプレイが夏の甲子園到達前に終わっているため)。段階5〜9の補正はシーズン終了時に2b側でも独立して行われます
- **問題5(OB機材贈呈、v1.2)**: 目標達成年に確実発生・未達成年に非発生の両方を実プレイで確認
- **未検証**: B(トーナメント規模)=6以外の都道府県での甲子園サブ段階(ベスト16/8/4)の境界、段階10〜19(連覇域)の挙動、パッチ適用状態での長期プレイ
